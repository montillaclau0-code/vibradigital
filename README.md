# Vibra Digital

Radio online con una página web donde se escucha la transmisión en vivo.

**Link:** https://montillaclau0-code.github.io/vibradigital/

## Qué incluye
- Reproductor en vivo con botón de play y onda de sonido animada
- Mascota interactiva que rebota cuando suena la radio
- Programación y sección para pedir canciones
- Diseño oscuro con estilo neón, adaptado a computador y celular

## Cómo funciona
Emisor (BUTT) → Servidor Icecast (Yanapak) → Oyentes (PC, tablet y teléfono)

1. Desde mi computador, el programa BUTT envía mi voz y la música al servidor.
2. El servidor de Yanapak reparte la transmisión por internet.
3. La página web reproduce esa transmisión con la etiqueta `<audio>`.

La radio solo suena mientras la transmisión esté activa.

## Tecnologías
HTML, CSS y JavaScript · BUTT · Icecast (Yanapak)
